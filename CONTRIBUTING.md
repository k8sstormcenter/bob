We welcome contribution in the form of:

- Requests for cloudnative applications to receive an SBOB, you should include:
  * an OCI artefact that deploys this application, currently a kustomize or manifest-bundle (helm support coming soon)
  * functional test suites or a link to them
  * non-functional test suites or a link to them
  * 


- Attack types: pointers to blogs/writeups/src/exploits that can be used in the `contrast tests` under the `--simulate` suite
  * bobctl recognises the language of your app and how you built your containers, all these ecosystems have different type of weaknesses
  * open an issue with a link if you want me to include it in the test coverage
 
- Corrections to the default subtract fragments:
  * those are best-guesses on what an application type from ecosystem X (go, C, cpp, java, node) can be vulnerable to or do not typically exhibit
  * if you have better heuristics, please open an issue
 
- Code-Contributions
  * are invite only, due to ethical reasons. If you know me (in real life), lets talk first.

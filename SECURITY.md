# Security Policy

## Scope

This repository does not contain actual source code, the published profiles are for reference only.
The usage of the `bobctl` binary is `not` intended for production use. It is publicly downloadable without any guarantees.
As it validates attack tests, it is ABSOLUTELY not intended to be used in any environment that could suffer damages. USE AT YOUR OWN RISK.

The nature of this repo is to validate detectability by mock attacking test-environements to calibrate detection/response.
It naturally follows that the examples could be abused even without any CVEs or vulnerabilities


## Future release for usage inside CI
The `bobctl binary` is currently not adversarially tested , nor fuzzed for potential attack vectors inside shared CI environments. USE AT YOUR OWN RISK
